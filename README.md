# ERP

A multi-tenant-ready ERP foundation incorporating the functional Import/Export ERP data model from `SmanSayeed/Import-Export-Company-ERP`.

## Included domain modules

- Banks and beneficiary banking details
- Importers / customers and contact details
- Sales / export contracts
- Shipment, transport, payment and LC/EXP details
- Product and weight/quantity fields
- Users and authentication-ready structure
- Seed/demo records derived from the source SQL dump

## Source

The domain schema and demo records were mapped from:
https://github.com/SmanSayeed/Import-Export-Company-ERP

This repository intentionally excludes generated/vendor files and the source repository's large binary archive.
